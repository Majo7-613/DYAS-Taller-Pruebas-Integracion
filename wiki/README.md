# Contenido para el Wiki de GitHub

El README del taller pide que la documentación viva en el **Wiki del repositorio** (no un PDF ni
un archivo dentro del código). Los archivos de esta carpeta son el contenido ya redactado para
cada página del Wiki — cópialos tal cual a `https://github.com/<tu-usuario>/<tu-repo>/wiki`,
creando una página nueva por archivo con el mismo nombre (sin `.md`):

| Archivo | Página del Wiki |
|---|---|
| `Inicio.md` | Home / Inicio |
| `Tipos-de-pruebas.md` | Tipos de pruebas |
| `Arquitectura-limpia.md` | Arquitectura limpia |
| `Pruebas-de-Integracion.md` | Pruebas de Integración |
| `Pruebas-con-Mockito.md` | Pruebas con Mockito |
| `Pruebas-de-Sistema.md` | Pruebas de Sistema (HTTP) + Pact |
| `Matriz-de-pruebas.md` | Matriz de pruebas de integración |
| `Resultados-cobertura.md` | Resultados (cobertura JaCoCo) |
| `Defectos-y-Diseno.md` | Gestión de defectos (resumen; el detalle está en `defectos.md`) |
| `Reflexion.md` | Reflexión final |
| `Conclusiones.md` | Conclusiones |

Los enlaces `[[Nombre-Del-Archivo]]` ya usan la sintaxis de wikilink de GitHub, así que funcionan
tal cual al pegarlos en el Wiki (GitHub las resuelve por el nombre de archivo/página).

**Falta agregar capturas reales**: el README pide capturas del reporte JaCoCo y de las respuestas
HTTP (Postman o terminal) en las páginas correspondientes — esta carpeta solo tiene el texto, no
imágenes, porque no puedo generarlas ni verlas desde aquí.
